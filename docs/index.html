01  The problem

Clearance is four people reading the same script for four different reasons.

Before a frame is shot, a screenplay goes through clearance. Rights counsel looks for brands, music, real people and artwork. A ratings consultant estimates what the MPA will assign. The insurer's reader looks for stunts, pyro, animals and minors. Territory advisors look for what gets cut in each release market.

They work serially, by hand, and expensively. Findings arrive as a memo weeks later, by which point the budget is locked. Independent producers, who need it most, often skip it entirely and discover the problem in post.

GREENLIGHT runs those four desks concurrently as agents and returns the same document in minutes — with every claim sourced.

02  The panel

Four gatekeepers, no shared context.

Each desk is an autonomous agent that investigates on its own terms — it reads scenes, runs research, chases ownership chains, and stops when it decides it is done. They cannot see each other's work, exactly as in a studio. An adjudicator reconciles them at the end, which is what a producer does.

DESK 01

Clearance Counsel

Brands, music, real people, artwork, locations. Chases ownership until it bottoms out — a song becomes a composition owner, then a master owner, then an administrator.

DESK 02

Ratings Board

Matches content beats against a corpus of published MPA rating rationales and returns the nearest released films — evidence, not a guess.

DESK 03

Safety Underwriter

Stunts, pyro, firearms, water, animals, minors. Reads back into the scene to establish who is present before deciding what an insurer will require.

DESK 04

Territory Censor

What gets cut, re-rated or refused in each release market, and which scenes need an alternate assembly.

04  How it is built

Each desk is a loop agent with a toolbelt.

A desk is not a prompt. It is given a worklist and a set of tools, and it decides what to read, what to research, how far to chase an ownership chain, and when it is finished.

GreenlightPipeline SequentialAgent ├ ScriptParser deterministic — screenplay → Scene[] ├ Triage LlmAgent → Entity[] + per-desk worklists ├ GatekeeperPanel ParallelAgent — four desks, concurrent │ ├ ClearanceCounsel LoopAgent(max_iterations=8) │ ├ RatingsBoard LoopAgent(max_iterations=4) │ ├ SafetyUnderwriter LoopAgent(max_iterations=6) │ └ TerritoryCensor LoopAgent(max_iterations=6) ├ VerificationPanel ParallelAgent — one verifier per filed flag ├ Adjudicator LoopAgent — may re-enter a desk via AgentTool └ ReportWriter deterministic → Report + marked-up script tools read_scene · find_in_script · research · query_precedent file_flag · note_open_question · done

Research is iterative because ownership is. A song is not one lookup: search it, find the composition and master are separately owned, research each rightsholder, find the master sits with a reissue label, research that. The entity graph expands as you research it, so no fixed number of calls covers it. Chase depth is capped at three; past that it is a human's job and the report says so.

Every flag is checked by something that did not write it. Each filed flag fans out to an independent verifier that receives the claim and the citation but not the desk's reasoning — a verifier shown the argument tends to ratify it. It can downgrade a flag to partially supported, or drop it entirely. That is what turns "every claim is sourced" from a prompt instruction into a guarantee.

Remedies interact, so adjudication is a loop. Replacing a brand rewrites an action beat, which may move a rating beat that Ratings Board already scored. When the adjudicator spots that, it calls the affected desk again through AgentTool with the proposed change and waits for a revised answer.

Loops that cannot end are just bills. Three independent stops: the desk calls done() and escalates, a hard max_iterations per desk, and a per-run research budget enforced inside the tool — when it is spent the tool replies "file what you have."

Parsing and scoring never touch a model. A parser that invents a scene number breaks every anchor downstream, and a score that moves between runs is not a score.
