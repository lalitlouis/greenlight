01  The problem

Clearance is four people reading the same script for four different reasons.

Before a frame is shot, a screenplay goes through clearance. Rights counsel looks for brands, music, real people and artwork. A ratings consultant estimates what the MPA will assign. The insurer's reader looks for stunts, pyro, animals and minors. Territory advisors look for what gets cut in each release market.

They work serially, by hand, and expensively. Findings arrive as a memo weeks later, by which point the budget is locked. Independent producers, who need it most, often skip it entirely and discover the problem in post.

GREENLIGHT runs those four desks concurrently as agents and returns the same document in minutes — with every claim sourced.

02  The panel

Four gatekeepers, no shared context.

Each desk reads independently, exactly as it works in a studio. An adjudicator reconciles them at the end — which is what a producer does.

DESK 01

Clearance Counsel

Brands, music, real people, artwork, locations, publications. Runs one live research task per entity and returns verbatim sourced text.

DESK 02

Ratings Board

Matches your content beats against a corpus of published MPA rating rationales and returns the nearest released films — evidence, not a guess.

DESK 03

Safety Underwriter

Stunts, pyro, firearms, water, animals, minors. Flags what an insurer will require on the call sheet and what it adds to the schedule.

DESK 04

Territory Censor

What gets cut, re-rated or refused in each release market, and which scenes need an alternate assembly.

04  How it is built

The architecture is the workflow.

A real clearance process is four independent desks that do not consult each other, reconciled at the end by a producer. That is exactly what the agent graph does — the fan-out is structural, not decorative.

ScriptParser deterministic screenplay → Scene[] ↓ EntityExtractor Gemini 2.5 Flash Scene[] → Entity[] ↓ ResearchCache Parallel Search one search per entity, shared ↓ GatekeeperPanel ADK ParallelAgent four desks, concurrent ├ ClearanceCounsel → Flag[] ├ RatingsBoard → Flag[] + rating ├ SafetyUnderwriter → Flag[] └ TerritoryCensor → Flag[] ↓ Adjudicator Gemini 2.5 Pro dedupe, reconcile, score ↓ ReportWriter deterministic Report + marked-up script

Parsing and scoring never touch a model. A parser that invents a scene number breaks every anchor downstream, and a score that moves between runs is not a score. Models are used only where judgement is genuinely required.

One search per entity, not one per desk. Four desks researching the same song independently would quadruple cost and latency for identical results, so research is cached in session state and shared.

Citations pass through untouched. A model may decide whether an excerpt supports a finding. It may never rewrite the excerpt. The whole value is that a producer can hand the quote to a lawyer.
